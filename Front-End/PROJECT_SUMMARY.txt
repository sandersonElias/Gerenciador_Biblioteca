🚀 COMO INICIAR
═══════════════════════════════════════════════════════════════════════════════

1. Instalar dependências:
   npm install

2. Configurar ambiente:
   cp .env.example .env
   # Editar REACT_APP_API_URL

3. Iniciar desenvolvimento:
   npm start

4. Acessar:
   http://localhost:3000

📡 API ENDPOINTS INTEGRADOS
═══════════════════════════════════════════════════════════════════════════════

POST   /auth                                    Login
POST   /auth/registrar                          Registrar usuário (ADMIN)
GET    /user/name/{name}                        Buscar usuários por nome

GET    /livro/todos                             Listar livros
GET    /livro/id/{id}                           Buscar livro por ID
GET    /livro/buscar/{filtro}/{termo}            Buscar com filtro
GET    /livro/populares                         Livros populares
POST   /livro                                   Criar livro (ADMIN)
PUT    /livro/{id}                              Atualizar livro (ADMIN)
DELETE /livro/{id}                              Remover livro (ADMIN)

POST   /autor                                   Criar autor (ADMIN)
GET    /autor/buscar/{autor}                    Buscar autores

POST   /genero                                  Criar gênero (ADMIN)
GET    /genero/buscar/{genero}                  Buscar gêneros

POST   /catalogacao                             Criar catalogação (ADMIN)
GET    /catalogacao/buscar/{catalogacao}        Buscar catalogações

GET    /exemplar/livro/{id}                     Todos os exemplares
GET    /exemplar/livro/{id}/disponiveis         Exemplares disponíveis
GET    /exemplar/livro/{id}/sugestao            Sugerir exemplar disponível
POST   /exemplar/livro/{id}/adicionar           Adicionar exemplares (ADMIN)

GET    /emprestimo/todos                        Listar empréstimos (FUNCIONARIO+)
GET    /emprestimo/id/{id}                      Buscar por ID
GET    /emprestimo/minha-conta/{email}          Empréstimos do usuário (ALUNO+)
GET    /emprestimo/user/{nome}                  Buscar por usuário
GET    /emprestimo/livro/{titulo}               Buscar por livro
GET    /emprestimo/status/{status}              Buscar por status
GET    /emprestimo/devolucao/{data}             Devoluções do dia
POST   /emprestimo                              Criar empréstimo
PUT    /emprestimo/renovar/{id}                 Renovar
PUT    /emprestimo/devolver/{id}                Devolver

GET    /reserva/todos                           Listar reservas (FUNCIONARIO+)
GET    /reserva/useremail/{email}               Reservas do usuário (ALUNO+)
GET    /reserva/livro/{livroId}                 Reservas por livro
POST   /reserva                                 Criar reserva (ALUNO+)
DELETE /reserva/{id}                            Cancelar reserva (ALUNO+)

POST   /solicitacoes-renovacao/{email}          Solicitar renovação (ALUNO+)
GET    /solicitacoes-renovacao/pendentes        Listar pendentes (FUNCIONARIO+)
PUT    /solicitacoes-renovacao/{id}/aprovar/{email}  Aprovar (FUNCIONARIO+)
PUT    /solicitacoes-renovacao/{id}/rejeitar/{email} Rejeitar (FUNCIONARIO+)
