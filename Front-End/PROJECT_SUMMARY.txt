🚀 COMO INICIAR
═══════════════════════════════════════════════════════════════════════════════

1. Instalar dependências:
   npm install

2. Configurar ambiente:
   cp .env.example .env
   # Editar REACT_APP_API_BASE_URL

3. Iniciar desenvolvimento:
   npm start

4. Acessar:
   http://localhost:3000

📡 API ENDPOINTS INTEGRADOS
═══════════════════════════════════════════════════════════════════════════════

POST   /auth                    Login
POST   /auth/registrar          Registrar usuário
GET    /livro/todos             Listar livros
GET    /livro/{id}              Buscar livro
GET    /livro/buscar/{f}/{t}    Buscar com filtro
GET    /livro/populares         Livros populares
POST   /livro                   Criar livro
PUT    /livro/{id}              Atualizar livro
GET    /emprestimo/todos        Listar empréstimos
POST   /emprestimo              Criar empréstimo
PUT    /emprestimo/renovar/{id} Renovar
PUT    /emprestimo/devolver/{id} Devolver
GET    /reserva/minhas          Minhas reservas
POST   /reserva/{livroId}       Criar reserva
DELETE /reserva/{id}            Cancelar reserva
